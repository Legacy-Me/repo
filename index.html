PinterestX

Changes the "info.plist" inside the app files to make the app identify as a newer version

Core Features

  • Fixes Pinterest crashes on iOS 5+ by sanitizing runtime version keys.
  • Empties CFBundleVersion and CFBundleShortVersionString.
  • Suppresses forced update modal dialogs on launch.

Deployment Instructions

  1. Add https://legacy-me.github.io/repo/ to your jailbreak manager.
  2. Search for and install PinterestX.
  3. Respring your device to apply Substrate hooks.

Prerequisites

  • iOS 5.0 or later
  • Pinterest 2.6+
  • MobileSubstrate runtime

DuolingoX

A fix for Duolingo on iOS 8 and 9. For now, login on iOS 8 is manual (With cookies/session data)

Core Features

  • Overrides the client User-Agent string.
  • Resolves network authentication errors seamlessly.
  • Lightweight zero-config payload.

Manual Package Delivery

  1. Download the payload:
    📦 DuolingoX.deb
  2. Deploy via shell: dpkg -i DuolingoX.deb
  3. Restart SpringBoard.
