About Me
Hi, I’m RetroWeirdos — a young developer with a deep passion for legacy technology and vintage iOS. Growing up surrounded by old devices, I fell in love with the golden era of iOS (versions 6 through 9) and the clean, charming design of Windows 8. As a legacy iOS enthusiast, I enjoy breathing new life into older Apple devices through sideloading, custom tweaks, and creative modifications. Whether it’s developing apps, exploring retro emulators, or tinkering with forgotten operating systems, I’m always chasing that nostalgic tech feeling. My goal is to preserve and celebrate the soul of older technology while building fun, unique projects for the community.

PinterestX

An iOS tweak that automatically fixes Pinterest on iOS 5+ by modifying the app's Info.plist version strings.

Features
  • Automatically fixes Pinterest crashes on iOS 5+
  • Modifies CFBundleVersion and CFBundleShortVersionString to empty strings
  • Blocks update alerts that appear on app launch
  • Supports multiple Pinterest bundle identifiers since there are some versions with weird bundle identifiers
  • The tweak remembers if Pinterest is already fixed to avoid unnecessary scans
Requirements
  • iOS 5.0+
  • Pinterest app version 2.6+ (tested with versions 2.6+, 3.4.1, and 3.8.1)
  • MobileSubstrate
Installation
  1. Add the repo https://legacy-me.github.io/repo/ to Cydia
  2. Install PinterestX
  3. Respring your device
  4. Launch Pinterest - it should now work without crashing!

DuolingoX

DuolingoX is a project that aims to fix Duolingo on iOS 9. This is accomplished by overriding the User-Agent string of the app.

This project has no affiliation with Duolingo.

Features
  • Overrides the User-Agent string to fix Duolingo on iOS 9
  • Allows Duolingo to connect to its servers without errors
  • Lightweight and easy to install
  • No configuration is required
  • Safe to use and does not modify other system files
Requirements
  • iOS 9.0 – 9.3.6
  • Duolingo app (latest compatible version for iOS 9)
  • Jailbroken device
  • Cydia Substrate
Manual Installation
  1. Download the .deb file
    📄 DuolingoX.deb (12.4 KB)
  2. Install using dpkg -i DuolingoX.deb
  3. Respring your device
